# Optional Style Contract

Apply the selected style as creative guidance inside the final H3 prompt.

- Do not output a brief, truth sheet, shot table, storyboard, asset manifest, confirmation card, or production plan as a separate deliverable.
- Do not ask the user for missing choices. Infer conservative defaults from the request and node settings, while omitting unverifiable facts.
- Do not mention Hub, canvas, tools, agents, generation steps, editing software, fallback models, or approval gates.
- Convert useful planning knowledge directly into visible action, camera, continuity, typography, dialogue, sound, and music instructions in the H3 mode format.
- Style rules are defaults, not a reason to overwrite explicit user choices.
